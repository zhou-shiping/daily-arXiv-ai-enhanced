Result: Provides an existence result for a functional integral equation with an illustrative example, alongside numerical solutions obtained via the modified homotopy perturbation method.

Conclusion: The generalized theorems successfully extend classical fixed point results and offer both theoretical existence guarantees and numerical approximations for functional integral equations.

Abstract: In our study, Darbo's fixed point theorem and the coupled fixed point theorem have been extended. The two theorems were generalized using $C-class$ mapping. Using the Darbo type theorem, we gave an existence result for a functional integral equation along with an appropriate illustration. In addition, we explored the numerical solution of a given functional integral problem using modified homotopy perturbation.
